# Caixa Compartilhada (nome provisório)

App web para centralizar o email de uma equipe num ambiente compartilhado:
todos veem os mesmos emails, usam as mesmas tags, acompanham quem respondeu
o quê e respondem de dentro do app.

- Visão do produto e decisões: [docs/VISAO.md](docs/VISAO.md)
- Arquitetura proposta: [docs/ARQUITETURA.md](docs/ARQUITETURA.md)

Status: fase de definição. Uso interno, Gmail primeiro, web, custo zero.
